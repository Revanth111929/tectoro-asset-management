  Problem:    Frontend extracted asset ID from WRONG response path
  
  API Returns:     { success: true, asset: { id: 42, ... } }
  Frontend Looked: response.data.id               (❌ undefined)
  Should Be:       response.data.asset.id          (✅ 42)
  
  Result:     newAssetId = undefined
              Invoice upload condition = false
              Invoice upload NEVER CALLED
              User saw file selected but nothing saved

  File:     frontend/src/pages/AssetAdd.js (Line 263)
  Changed:  1 line of code
  
  BEFORE (BUG):
    const newAssetId = response.data.id || response.data.asset_id;
    // Always undefined because response.data.id doesn't exist
  
  AFTER (FIX):
    const newAssetId = response.data.asset?.id || response.data.id || response.data.asset_id;
    // Correctly extracts from response.data.asset.id
  
  Impact:   Minimal (1 line, +36 bytes bundle size)
