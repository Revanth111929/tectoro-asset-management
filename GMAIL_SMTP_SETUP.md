# Gmail SMTP Setup Guide - Fix Authentication Error

## Problem
You're getting "Authentication failed — check username/password" when testing email.

## Solution
For Gmail, you **cannot use your regular Gmail password**. You must use an **App Password**.

---

## Step-by-Step: Generate Gmail App Password

### Step 1: Enable 2-Step Verification
1. Go to https://myaccount.google.com/security
2. Click on **"2-Step Verification"**
3. If not enabled, click **"Get Started"** and follow the prompts
4. **Important**: You MUST have 2-Step Verification enabled to use App Passwords

### Step 2: Generate App Password
1. Go to https://myaccount.google.com/apppasswords
   - Or: Google Account → Security → 2-Step Verification → App passwords
2. You may need to sign in again
3. Under "Select app", choose **"Mail"** or **"Other (custom name)"**
   - If choosing "Other", name it: **"IT Asset Management"**
4. Click **"Generate"**
5. Google will show you a **16-character password** like: `abcd efgh ijkl mnop`
6. **Copy this password** - you won't see it again!

### Step 3: Configure in Asset Management System
1. Go to **Settings → Email Config** (or the email configuration page)
2. Enter these settings:

```
Sender Email:    revanthraj31992@gmail.com
Sender Name:     Tectoro IT Assets
SMTP Server:     smtp.gmail.com
SMTP Port:       587
SMTP Username:   revanthraj31992@gmail.com
SMTP Password:   [paste the 16-character app password here]
TLS:             Enabled (checked)
```

### Step 4: Test
1. In "Test Email Connection" section
2. Enter test recipient: `revanth4551@gmail.com`
3. Click **"Send Test"**
4. Should show: ✅ "Test email sent successfully"

## Common Mistakes

### ❌ Wrong:
- Using your regular Gmail password
- Using your Google account password
- Leaving spaces in the app password (system should handle this, but remove if issues persist)

### ✅ Correct:
- Using the 16-character App Password generated by Google
- Example format: `abcdefghijklmnop` (no spaces, 16 characters)

## Troubleshooting

### Still getting authentication error?

#### 1. Verify App Password is correct
- Go back to https://myaccount.google.com/apppasswords
- Delete the old app password
- Generate a NEW app password
- Copy it carefully (no extra spaces)
- Paste into the system

#### 2. Check 2-Step Verification
- Make sure 2-Step Verification is ENABLED
- Without it, App Passwords option won't appear

#### 3. Try without spaces
If the app password has spaces (like `abcd efgh ijkl mnop`), remove them:
```
Before: abcd efgh ijkl mnop
After:  abcdefghijklmnop
```

#### 4. Check "Less Secure Apps"
- Google has deprecated this, so don't try to enable it
- Use App Passwords instead (the modern way)

#### 5. Account Security
- If your account has suspicious activity flags, Google might block SMTP
- Check: https://myaccount.google.com/security-checkup

## Testing Process

### What happens when you click "Send Test":

1. **System connects** to smtp.gmail.com:587
2. **Initiates TLS** encryption
3. **Attempts login** with username and password
4. **Sends test email** to recipient
5. **Shows success/error** message

### Success looks like:
```
✅ Test email sent successfully!
Check revanth4551@gmail.com inbox.
```

### Failure looks like:
```
❌ Authentication failed — check username/password
```

## Security Notes

### App Passwords are safe because:
- ✅ They're specific to one app/device
- ✅ They don't give full account access
- ✅ You can revoke them anytime
- ✅ They don't work for signing in to Gmail web
- ✅ They only work for SMTP/IMAP

### To revoke:
1. Go to https://myaccount.google.com/apppasswords
2. Click "Remove" next to the app password
3. It stops working immediately
